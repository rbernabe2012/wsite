Twenty CRM

Un CRM Moderno para Gestionar tu Proceso de Ventas

Twenty es un CRM de nueva generación, de código abierto, diseñado para que los equipos de ventas gestionen sus oportunidades y relaciones con clientes de una forma visual e intuitiva. Olvídate de los CRMs complejos y obsoletos.

Organiza tus Ventas

Características Principales

✔Gestión de pipeline de ventas en vista Kanban
✔Gestión de contactos y perfiles de cliente 360º
✔Administración de cuentas y empresas
✔Seguimiento de oportunidades y negociaciones
✔Registro de actividades (llamadas, emails, reuniones)
✔Gestor de tareas y recordatorios para el equipo
✔Calificación de leads (Lead Scoring) personalizable
✔Informes de ventas y analíticas de rendimiento
✔Dashboards visuales y personalizables
✔Integración con el correo electrónico
✔Sincronización con calendarios (Google, Outlook)
✔Código abierto: opción de auto-alojamiento (self-hosting)
✔Potente API GraphQL para integraciones
✔Creación de campos personalizados para adaptar el CRM
✔Permisos y roles de usuario para control de acceso
✔Comentarios y menciones para colaboración en equipo
✔Catálogo de productos y servicios
✔Soporte para múltiples monedas e idiomas
✔Interfaz de usuario moderna, rápida y limpia
✔Búsqueda global instantánea en todo el CRM
